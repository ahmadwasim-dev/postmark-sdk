# Postmark SDK

A multi-language SDK for the Postmark Email API, generated using the Voxgig SDK Generator toolchain.

## About

This project demonstrates the use of the Voxgig SDK Generator to create client SDKs from OpenAPI specifications. The SDK targets TypeScript, Python, and Go languages.

## API Information

**Postmark** is a transactional email service that provides reliable email delivery with detailed analytics.

- **Documentation**: https://postmarkapp.com/developer
- **OpenAPI Spec**: https://github.com/api-evangelist/postmark
- **Free Tier**: Available for testing

## What's Included

- `openapi.yml` - Postmark Email API OpenAPI 3.2.0 specification
- `.sdk/` - Voxgig SDK build directory with target configurations for TypeScript, Python, and Go
- `DEVELOPER_EXPERIENCE_REPORT.md` - Developer experience evaluation and observations
